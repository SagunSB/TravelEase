# TravelEase - Travel and Tourism Management System

## Overview

TravelEase is a Java-based desktop application designed to simplify travel and tourism management operations. The system provides an easy-to-use interface for managing customers, tour packages, hotel bookings, payments, and destination information in a centralized platform.

The project was developed using Java Swing for the graphical user interface and MySQL for database management.

## Features

### Customer Management

* Add new customers
* Update customer details
* View customer information
* Delete customer records

### Package Management

* Create travel packages
* View available packages
* Book travel packages
* Manage package details

### Hotel Management

* Browse hotels
* Book hotels
* View hotel booking information

### Booking Management

* Track customer bookings
* View booked packages
* View booked hotels
* Generate booking details

### User Authentication

* User registration
* Login system
* Forgot password functionality

### Payment Module

* Secure payment interface
* Booking confirmation process

### Additional Features

* Attractive Swing-based GUI
* Destination information display
* Modern UI theme support
* Easy navigation between modules

## Technologies Used
